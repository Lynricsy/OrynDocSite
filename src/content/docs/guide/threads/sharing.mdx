公开分享给线程生成一条只读链接，拿到链接的人不用登录就能看这段对话：可以是创建那一刻的快照，也可以实时跟随后续进展。适合把一次排查过程或一份结论发给不使用 Oryn 的人。

<Aside type="caution">
链接打开即可访问，不需要登录。分享前先确认对话里没有不该公开的内容；Oryn 会扫描疑似密钥，但不扫描图片内容。
</Aside>

## 创建分享链接

在线程页头打开「更多操作 → 分享…」，弹出「分享线程」对话框。对话框里列出这个线程已有的「公开链接」；要新建一条，在「新建链接」下：

1. 选择模式：
   - 「快照」：冻结在当前内容。之后被改写或删除的消息不再公开，新内容不会出现，标题也冻结在创建时。
   - 「实时」：之后的新内容也会公开，访客打开的页面随线程实时更新。
2. 点「创建链接」。没有疑似密钥时直接创建，提示「已创建，链接已复制」。

链接形如 `https://oryn.example.com/s/<32 位十六进制>`。有公开链接的线程，页头显示「已公开」标记，点它可以管理链接。

公开的内容包括消息、思考、工具调用及其输出、图片与用量；不含子 Agent 的转录与被回退的分支。

## 处理疑似密钥

创建前，Oryn 扫描将要公开的消息、线程标题和将要列出的附件名。有命中时，对话框显示「发现 N 处疑似密钥」，并说明「这些内容会随链接公开。确认可以公开再继续；否则先在线程里处理，再重新创建。」

每处命中写明类型、位置与脱敏后的片段（只露出前 4 个与后 2 个字符）。类型有：

「已保存的密钥」「私钥」「API 密钥（sk-）」「GitHub 令牌」「AWS 访问密钥」「Google API 密钥」「Slack 令牌」「JWT」「Oryn 令牌」「Authorization 头」「URL 内嵌凭据」

点一处命中的「定位」，对话框关闭并滚动到那条消息。命中超过 200 处时「仅显示前 200 处」。

确认可以公开时，勾选「我已检查，仍然分享」，再点「仍然创建」。创建后的链接记下你确认过的命中数，在设置里显示为「确认过 N 处疑似密钥」。

## 分享页上有什么

分享页的页脚写着「由 Oryn 分享 · 只读」。快照页带「快照 · 日期」标记。访客可以：

- 阅读分享范围内活动分支上的对话。
- 点「复制链接」。
- 点「Markdown」导出整段对话为 `.md` 文件；其中单个工具结果截到 4000 字符。
- 查看已发布的附件，以及被公开消息引用的附件和图片。

分享页不包含线程 id、环境、项目、标签与模型配置。访客打开页面不会唤醒环境，也不算作有人在查看该线程。分享页带 `noindex` 标记，不让搜索引擎收录。

### 头像与身份

分享页显示 Agent 的名字与头像，以及这段对话用到的角色的名字与头像；只带出分享范围内实际用到的头像。快照固定为创建时的样子，实时页跟随当前设置。

### 对话里的视图

声明式视图照常显示，但控件禁用；HTML 视图照常运行，但回传无效。撤销分享后，视图的帧随即失效。视图的工作方式见[视图：对话里的交互界面](/guide/artifacts/views/)。

## 撤销分享

任选一处：

- 在「分享线程」对话框里，对某条公开链接点「撤销」，再点「确认撤销」。
- 设置 → 分享与 Artifacts →「公开的线程与文件」，在「公开的线程」里打开该链接的更多操作并撤销。

撤销后链接立即失效，已打开页面的访客也看不到后续内容；再打开链接会看到「链接不存在或已被撤销」。删除线程也会让它的分享链接失效。

## 公开单个文件

不想分享整段对话时，可以只公开一个文件：

- 附件：在附件对话框里发布。
- 环境里的文件：在文件面板的右键菜单里发布。发布的是此刻的副本，它会成为该线程的一个附件。

公开文件的链接形如 `https://oryn.example.com/f/<32 位十六进制>/<文件名>`。在设置 → 分享与 Artifacts 的「公开的文件」里撤回：公开链接立即失效，附件本身仍留在线程里。

## 限制

| 项 | 上限 |
|---|---|
| 每个线程未撤销的分享链接 | 20 条 |
| 疑似密钥列出的命中 | 200 处 |
| `.md` 导出里的单个工具结果 | 4000 字符 |
| 实时分享的同时访客连接 | 每条分享 64 个，全站 512 个 |
| 公开的环境文件 | 单个 100 MiB |
