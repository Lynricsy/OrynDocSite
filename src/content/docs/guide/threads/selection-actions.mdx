读转录、看代码或 diff 时，你常常想就其中一小段追问一句，又不想打断正在运行的回合。选区动作把选中的文字连同上下文交给模型，答案显示在选区旁边；右键菜单则把复制、打开、暂存这类操作放在你点的位置上。

## 对选中的文字提问

选中一段文字后，菜单里的 AI 组有：

- 「解释」「就此提问…」「翻译」，直接列出。
- 你自定义的动作，放在「更多动作」里。

同一菜单里还有「引用回复」「引用到输入框」、复制，以及「搜索」（在命令面板里搜这段文字）。

AI 动作走旁路提问：选区原文、前后各 120 字和来源（回复、思考、工具卡、文件路径与行号）拼成问题。旁路提问不打断正在运行的主回合，并复用主会话的前缀缓存。

<Shot id="site/explain-card" alt="选中转录里的 thaw-pending 后弹出的解释卡：标题「解释」，正文是旁路回答，下方是追问输入框、「复制回答」与「在旁路提问里打开」" />

结果显示在选区旁的解释卡里。在解释卡上你可以：

- 在「接着这个话题问…」里追问。
- 点「复制回答」。
- 点「在旁路提问里打开」，转到「旁路提问」对话框继续。

窄屏上结果用对话框显示。

## 管理自定义动作

设置 → 输入与快捷键 →「选区快捷动作」。每个动作有「名称」与「提示词」，提示词写成对选中内容的指令，例如「找出这段话里的漏洞」。点「添加动作」新增，用「上移」「下移」调整顺序。

自定义动作出现在选区的右键菜单里，把你写的提示词连同选中的内容一起交给模型。

## 在哪里能打开右键菜单

| 位置 | 菜单项 |
|---|---|
| 转录消息 | 「复制消息」、「引用整条」（助手消息），与消息行内的「⋯」相同 |
| 链接、图片、代码 | 打开或复制链接；复制、下载图片，或作为附件引用；「复制代码」、「解释这段代码」 |
| 工具卡 | 复制命令、路径或输出，「在文件面板打开」，「解释这次调用」 |
| 侧栏线程行、收件箱行 | 打开、状态、改名 / 标签 / 分叉、归档与删除 |
| 终端 | 有选区时的选区动作，「粘贴」「全选」「清屏」 |
| 编辑器、文件查看器 | 选区动作（带文件路径与行号）、「剪切」「粘贴」、「复制路径与行号」 |
| 改动列表与 diff | 「在文件面板打开」、「复制路径」、「暂存」/「取消暂存」；diff 里的选区可以解释 |

## 用键盘或触屏打开菜单

| 方式 | 在哪里生效 |
|---|---|
| 右键 | 上表所有位置。输入框里，以及按住 <kbd>Shift</kbd> 右键时，弹出的是系统菜单 |
| 菜单键或 <kbd>Shift</kbd>+<kbd>F10</kbd> | 终端与普通输入框之外的所有位置 |
| 触屏长按 | 只在转录消息、代码块、工具卡、侧栏线程行、收件箱行、文件树、改动列表与 Artifacts 卡片上 |

终端只响应右键；终端里的程序开了鼠标上报时不弹菜单。菜单键与触屏长按在终端里都留给 xterm 和终端里的程序。

## 限制

| 项 | 上限 |
|---|---|
| 自定义动作 | 12 条 |
| 动作名称 | 24 字 |
| 动作提示词 | 2000 字 |
| 选区前后附带的上下文 | 各 120 字 |
