*本页回答：线程的对话里出现的每种元素表示什么？*

线程页中间一栏是转录：你发出的消息、Agent 的回复、它调用的工具及结果按时间排列。回合进行中，Agent 的输出流式到达；回合结束后，转录就是这段工作的完整记录。

## 回合头

每个 Agent 回合以回合头开始：头像、名字和模型胶囊。回合刚开始、Agent 还没有任何输出时，转录末尾立即出现回合头，下面是三个依次跃动的点；首个可见的正文、思考或工具块到达后，三点消失。回合中途在两次工具调用之间，显示「工作中」与当前活动。

模型或思考档位的切换不单独成一行，回合头的胶囊与角标、输入框已经显示了它们。

### 思考档位

模型胶囊右下角的图标是这一回合实际生效的思考档位。首屏角色弹层也直接选中实际生效的档位，没有「默认」这一项。实际档位的推定顺序是：显式指定的档位优先，其次是模型自带的默认档位，再次是会话起始档位（default role 的显式档位，或 `config.yml` 的 `defaultThinkingLevel`），最后按模型能力收窄。

推不出实际值时，弹层只列出可选档位，不选中任何一项。

## 你的消息

你的气泡里每个字符都和原文一样显示，空白、换行、`#`、`**`、反引号、`>`、列表符号与围栏行都在，只加样式：语法记号变淡，标题与粗体加粗，斜体与删除线显示对应样式，行内代码与代码块用等宽字体，引用变弱色，链接与裸地址可点（只认 http(s) 与 mailto）。选中复制得到的就是原文。开头的引用回复块仍按原文显示。

## 工具卡

Agent 每次调用工具，转录里就出现一张工具卡。

<Shot id="site/tool-cards" alt="三张收起的工具卡：read 卡写明意图并显示 18 行，两张 edit 卡写明意图并显示增删行数，卡间是一段助手正文" />

- **头部**：显示这次调用的意图，收起与展开时都一样；没有意图时才显示参数摘要。右侧读数说明结局，例如 todo 的完成进度格、wait 等待中的任务与结局、搜索命中数、edit 的 `+N −M`；运行中实时走表。
- **展开体**：上半是输入，下半是输出井，用底色区分。输入与输出按各工具的原生形态排版：搜索答案按 Markdown 渲染并附来源卡片，网页正文直接排版（外部内容不自动加载远程图片），另有子 Agent 名册、问卷回执、调试器面板、终端窗口等。
- **语法高亮**：约 60 种语言。diff 按文件语言高亮代码部分，grep 与 ast_grep 的结果按文件逐段高亮，命令行统一按 bash 高亮。
- **当前一批默认展开**：线程工作中时，最后一条助手消息里的工具调用（并行调用算一批）默认展开；模型开始下一批或回合结束时自动收起。你手动开合过的卡片以你的操作为准。

## bash 的 Pseudo 视图

bash 卡默认显示 Oryn Core 生成的 Pseudo 视图：令牌着色，失败的步骤标 ×，跳过的步骤弱化，变量显示终值。你可以切回原始命令。运行中视图随执行轨迹更新，正在执行的那行行首标 `›`，其余行弱化。

Runner 线程的 bash 卡只有最终结果带 Pseudo 视图。

## 后台任务

转入后台的 bash 或 eval 调用，头部带一枚随任务走的标记：后台运行中（圆点扩散，状态位转圈）、后台已完成、失败、已停止，卡片收起时也在。展开体末段是任务的最近输出与「查看任务」。

任务注入会话的消息显示为事件行，而不是普通工具卡：

- 「后台任务 bg_3 已完成 / 失败 / 已停止」这样的一行，带命令与耗时，点开看结果并可复制；子 Agent 的任务可以直接打开它。
- 一次交付多个任务时汇成一行。
- `notify` 命中时显示「输出匹配 /正则/」。
- 常驻进程退出。

信息面板也像子 Agent 一样列出后台任务，见[信息面板](/guide/workbench/info-panel/)。

## 思考块

模型思考时，思考块自动展开，文字平滑显现，窗口限高约 8 行并跟住最新一行，上面还有内容时顶部渐隐。思考结束（开始正文、调用工具或回合结束）后，思考块自动合上成一行预览。你手动开合过的以你的操作为准。

## 表格

助手正文里的 Markdown 表格按内容需要放宽：两侧空间够时对称伸出正文列，最宽到转录行宽减去两侧各 1rem，封顶 72rem；再放不下时横向滚动。

悬停在任一 Markdown 表格上（触屏点一下），右上角出现三个按钮：

| 按钮 | 得到什么 |
|---|---|
| 「复制为 CSV」 | CSV 文本 |
| 「复制为 Markdown 表格」 | 表格原文，保留行内格式 |
| 「复制为图片」 | PNG 图片 |

## 动效

贴底时转录平滑跟随新内容，往上滚一下就停止跟随。新消息与新块从下方淡入，流式正文匀速显现，工具卡与思考块的展开、收起有高度过渡。打开线程、翻看历史、加载更早的消息时不播放动画；系统开启「减少动态效果」时一律直接到位。

## 不显示的内容

- 模型与思考级别的切换提示不单独成行。
- omp 的 `xd://: mounted …` 挂载变动提示不进转录；模型照样会随下一条消息得知变动。
