同时跑着几条线程时，Agent 会在不同时刻停下来：问你一个问题、等你批准计划、出错，或者做完了等你看。收件箱把这些汇在一处，按紧急程度排好，能一键回答的问题直接在行内回答。

## 看哪些线程在等你

侧栏的「需要你」汇总等待输入或出错的线程，子线程的状态上卷到父线程那一行。

点进收件箱（地址 `/inbox`，也可以在命令面板里选「打开收件箱」），顶部是大号的待处理数（「项待你处理」）与按状态筛选的胶囊。分节按紧急程度排列：

1. 「等你处理」
2. 「出错」
3. 「已完成未读」
4. 「运行中」

<Shot id="site/inbox" alt="收件箱：顶部是 4 项待你处理与状态筛选胶囊，「等你处理」分节的两行在问题下方列出选项按钮，「已完成未读」分节列出完成摘要" />

每行写明它在等你什么：未作答的问题原文、完成摘要、出错原因或当前意图。从别的线程分叉出来的线程标出「派生自「…」」。

- 页头的「分组方式」在「按状态」与「按项目」之间切换，选择保存在本机。顶部的状态筛选只在本页生效。
- 点「去回复」打开线程。「已完成未读」与「出错」的行在悬停时可以「标为已读」或归档（没有悬停的设备上不显示，在线程页照样能做）；「已完成未读」分节上有「全部标为已读」。
- 空闲且已读的线程不列出；每节内按最后活动时间排列，新的在前。

## 在收件箱里一键作答

可以一键作答的提问，在行下方直接列出选项按钮，点一下即作答。行内显示的是问题原文的纯文本，不解析反引号等标记，所以工具审批里看到的就是会执行的命令。

能一键作答的是只需选一项的提问：单选、是 / 否确认，以及只有一道单选题的问卷，且只有 2–3 个选项、每个选项不超过 24 个字且不换行。需要输入文字、输入密钥、多选、多道题、表单与计划审批，或选项超出上述限制时，都要打开线程作答。

问题已在别处（另一台设备、通知或命令行）作答时，按钮撤回并提示「已在别处作答」。同一线程还有更早的未答提问时，行内换成那一条。

手机与浏览器通知上也能直接作答，见[通知渠道](/guide/automation/notifications/)。

## 读懂出错原因

出错的行先把原因归成一句话，并带上镜像名、退出码（「退出码 N」）等小签；原始错误降为一行等宽小字。归类有：

- 「拉取环境镜像被拒绝：镜像不存在或没有权限」
- 「找不到环境镜像或快照」
- 「容器运行时命令执行失败」
- 「环境已启动，但一直没有连上控制面」
- 「fork 时复制环境失败」
- 「工作目录不在这台 runner 允许的范围内」
- 「agent 启动参数无效」
- 「agent 启动超时」
- 「agent 没能启动」

更多排查思路见[故障排查](/admin/operations/troubleshooting/)。

## 在线程里回答提问

Agent 提问时，对话框停靠在输入框的托盘里，标题是「agent 在提问」（表单是「请填写」）。

- 推荐的选项标有「推荐」，可多选的题标有「可多选」，必填项标有「必填」。
- 选项之外可以在「其他回答…」里写自己的答案。
- 表单底部显示「已填 N/M」，可以用快捷键提交。
- 同一线程排着多个请求时显示「另有 N 个待答」；有倒计时的请求显示剩余秒数。

同一个请求在你所有打开该线程的设备上都会出现，任一端作答后其余端自动关闭，先答者生效。

问卷超时时，按表单当前的值自动提交，工具卡标为「超时自动提交」，这不是你的选择；超时时仍有必填项为空，则标为「超时未作答」。

工具审批的标题首行是要调用的工具，其下的「来源」「原因」与参数（命令、路径、JSON）原样显示，避免截断后盲批。

## 审批计划

在计划模式（`/plan`）下，Agent 先写计划、经你批准再动手。计划写好后弹出「计划提案：标题」，正文是计划文件的路径与内容，底部五个选项：

| 选项 | 结果 |
|---|---|
| 「执行」 | 批准并开始执行 |
| 「压缩后执行」 | 批准，先压缩上下文再执行 |
| 「保留上下文执行」 | 批准，保留当前上下文执行 |
| 「仅保存」 | 先确认保存路径，计划保存后开启新会话，提示「计划已保存到 …，已开启新会话」。路径可以写相对路径，按 Agent 的工作目录解析 |
| 「提修改意见」 | 先在「修改意见…」里写意见，再发回；计划被驳回，仍处于计划模式 |

选「执行」「压缩后执行」或「保留上下文执行」时，对话框里有「继续使用」下拉框，用来挑执行计划所用的模型档位：每项显示角色（role）名与对应的模型，初始选中 `default`。可选的档位不足两个时不显示这个下拉框。

计划的保存位置，以及批准后没有开始执行的原因（例如压缩失败），写在转录的提示行里。

关掉对话框后，输入框托盘里留一行「待审计划：标题」与「审阅」按钮；也可以输入 `/plan-review` 重新打开。

## 在命令行里作答

`oryn thread attach <线程 id>` 挂到线程上：有待答请求时，输入的每一行作为作答（编号或文字）；有待审批的计划时，输入编号或选项名批准，`save <路径>` 保存计划（相对路径按 Agent 的工作目录解析），其它文字作为修改意见发回。命令行批准时不能挑执行档位。完整说明见 [`oryn thread`](/reference/cli/thread/)。
