Agent 走错了方向时，你不必新开线程：回退把会话移回之前的某个位置，原来的路径保留为一条分支，随时能在会话树里切回；分叉则从某个位置复制出一个新线程，两条线并行推进。

## 回退到之前的某一步

在空闲的线程里打开回退选择器，任选一种方式：

- 输入框为空时，连按两次 <kbd>Esc</kbd>（间隔不超过 500 毫秒）。
- 输入 `/branch` 或 `/rewind`。
- 在某条用户消息的菜单里点「回到这里编辑」。

进入回退后，页头下方出现「回退」状态胶囊（「选择要继续的位置」），转录里原位框选目标，缺省是最后一个可回退的对象。用户消息、助手回复与工具调用都可以选；所选位置之后的内容变淡，表示回退后会被裁掉。

| 按键 | 作用 |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd>（或 <kbd>K</kbd> <kbd>J</kbd>） | 逐条切换 |
| <kbd>←</kbd> <kbd>→</kbd> | 在用户回合之间跳转；位于分叉处时切换分支 |
| <kbd>Home</kbd> <kbd>End</kbd> | 跳到第一个或最后一个目标 |
| <kbd>F</kbd> 或 <kbd>/</kbd> | 按关键词过滤消息或工具 |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | 展开或收起全部工具与思考块 |
| <kbd>Enter</kbd> | 确认回退 |
| <kbd>Esc</kbd> | 关闭过滤；不在过滤中时退出回退 |

也可以直接点选转录里的目标行。确认按钮随目标变化：

- 选中你的一条消息时是「回退并编辑」：会话移回这条消息之前，原文与附件放回输入框，提示「已回退，原文已放回输入框」。附件直接复用原来的上传，图片连同内联副本一起放回；全局助手对话里的文件库文件不会放回。
- 选中助手回复或工具调用时是「回退到这里」：会话保留到这一步，提示「已回退到所选位置」。

提示条上的「撤销」把会话与输入框都恢复到回退之前。

### Esc 在不同状态下的含义

| 状态 | 连按两次 <kbd>Esc</kbd> |
|---|---|
| 回合进行中 | 中断回合 |
| 空闲，输入框为空 | 打开回退选择器 |
| 空闲，输入框里有字 | 不计入连按，草稿不受影响 |

## 在会话树里切换分支

回退后，原来的路径成为一条分支。输入 `/tree`，或在线程页头点「会话树」，打开会话树：

- 顶部可以搜索，并按「全部」「仅用户消息」「有标签」筛选。
- 当前所在的路径标为「活动分支」，末端节点带「叶子」标记；可以给节点「编辑标签」。
- 选中节点后点「跳转」把会话切到那里。跳到一条用户消息时，它的原文与附件同样放回输入框。
- 勾选「带摘要跳转」时，可以在「摘要要求（可选）」里写要求；摘要生成期间可以点「中止摘要」。

## 分叉出一个新线程

输入 `/fork`，或在线程页头的菜单、侧栏线程行的右键菜单里选「分叉」，打开「分叉线程」对话框。从某条消息发起时显示「从选中的消息分叉。」，否则显示「从当前位置分叉。」。

新线程的环境有两种方式：

| 选项 | 效果 |
|---|---|
| 「共用当前 orb」 | 新线程在同一台机器上运行，文件改动互相可见 |
| 「连环境一起分叉」 | 快照当前环境出一台副本，新线程在副本上运行 |

Runner 线程与 box 上的线程只能共用，不能连环境一起分叉。点「分叉」后跳到新线程。

### 用命令行分叉

```bash
# 从当前叶子分叉，共用当前环境
oryn thread fork <线程 id>

# 从指定条目分叉，并把环境快照成一台副本
oryn thread fork <线程 id> --entry <条目 id> --env copy
```

`--env` 只能是 `share`（缺省）或 `copy`；命令打印新线程的 id，加 `--json` 以 JSON 输出新线程。完整参数见 [`oryn thread`](/reference/cli/thread/)。

### 共用环境的线程何时删除环境

几个线程共用一台环境时，只有最后一个引用它的线程（包括已归档的）被删除，环境才一并删除。定时任务按保留数自动归档旧运行时，也只回收旧运行独占的环境；从它「共用 orb」分叉出的线程还在用，环境就保留。完整规则见[环境如何随线程生灭](/guide/environments/lifecycle/)。

## 限制

- 连按两次 <kbd>Esc</kbd> 的间隔不超过 500 毫秒。
