线程多了以后，靠侧栏翻找很慢。命令面板是一个搜索框：输入几个字，就能跳到线程、项目、Space、Artifacts 或某个设置，执行常用操作，或者找到很久以前某段对话里说过的一句话。

## 打开命令面板

在任何页面按 <kbd>Ctrl/⌘</kbd>+<kbd>K</kbd>。输入框提示「搜索线程、Artifacts、对话内容、设置与操作…」。用 <kbd>↑</kbd> <kbd>↓</kbd> 选择，<kbd>Enter</kbd> 打开，<kbd>Esc</kbd> 关闭。

## 跳到线程、项目与设置

结果按类分组：

| 分组 | 内容 |
|---|---|
| 「最近线程」「最近的 Artifacts」 | 最近的线程与 Artifacts |
| 「线程」 | 线程标题匹配的线程 |
| 「Artifacts」 | 匹配的 Artifact |
| 「对话内容」 | 对话正文的全文命中，见下一节 |
| 「项目」「空间」 | 匹配的项目与 Space |
| 「设置」 | 匹配的设置分区 |
| 「操作」 | 「新建线程」「打开收件箱」「打开统计」「打开 Artifacts」「打开 Boxes」「打开 Provider 总览」「打开设置」「切换明暗」 |

某组结果较多时，点「显示全部 N 项」展开。

## 搜索对话正文

输入的文字同时在所有对话的正文里搜索，命中列在「对话内容」组里：每条带线程标题、命中前后的片段与时间，命中的词加粗，新的在前。点一条命中直接打开线程并定位到那条消息；要看更多命中，点「显示更多对话内容」。

### 搜得到什么

- 只搜你的消息与 Agent 回复的正文。思考、工具调用、工具结果与图片不进索引。
- 已归档线程里的消息照样能搜到，结果里标「已归档」。
- 输入按空白切成几个词，每个词都命中的消息才算命中。引号、`OR` 等搜索语法字符没有特殊含义，按普通文字匹配。
- 中文、日文与代码标识符不需要空格分词也能搜到。三个字及以上的词忽略大小写与变音符；不足三个字的词（例如「部署」）按子串匹配，只忽略英文字母的大小写。

### 分叉线程里的重复消息

分叉会把源线程的消息复制到新线程。同一条消息只计一次，显示在最早创建的那个线程里，并注明「另有 N 个 fork」。源线程删除后，分叉里的那一份自动成为命中。

### 结果不全时

索引版本变化时，控制面启动后在后台为历史消息补建索引，可以中断，下次启动接着做。补建期间面板提示「历史消息仍在建立索引，结果可能不全」。

## 用 API 搜索

同一份数据也可以通过 `GET /api/v1/search?q=<关键词>` 查询，每页缺省 20 条、最多 50 条，按消息时间从新到旧翻页。参数与响应见 [API 参考](/reference/api/)。

## 限制

| 项 | 上限 |
|---|---|
| 搜索文字 | 200 个字符 |
| 词数 | 8 个 |
| 命中片段 | 160 个字符 |
| API 每页条数 | 缺省 20，最多 50 |
