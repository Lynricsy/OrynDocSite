主人记忆是全局助手专用的一份只关于你的记忆，存在 bank `oryn-owner` 里。它与 Agent 的工程记忆共用同一个 Hindsight，彼此分开存放。助手对话启动时，它把整理好的主题附在系统提示词末尾，所以助手在新对话里也记得你的偏好与近况。

<Requires ids={['hindsight']} />

前提是工程记忆已经启用并连上，管理页状态为「正常」，见[记忆](/guide/agent/memory/)。否则「助手记忆」分区只显示提示。

## 开启助手记忆

1. 打开「更多 → Agent → 记忆 → 助手记忆」。
2. 打开「开启助手记忆」。
3. 在「主人的名字与别名」里填你的名字与别名，点「保存名字」。

名字与别名写进 bank 的抽取说明，抽取时统一写成「主人」。别名填不全时，同一个人会被拆成两个实体。

首次开启时回填最近 30 天内有活动的对话与线程，进度显示在「助手记忆状态」卡的「回填进度」里。

## 了解何时写入、写什么

控制面每 5 分钟扫描一次，满足条件的对话按回合写入：

| 来源 | 何时写入 |
|---|---|
| 助手对话 | 你的最后一条消息之后空闲 30 分钟，或被归档 |
| 工作线程（含 Space 子线程与 Runner 线程） | 空闲且 30 分钟没有活动、归档或交付后 |

每个回合写入你的话加 Agent 的最后一条回复，回复截到 600 字。工具调用、工具结果、thinking 与超过 8 行的代码块不写。

写入前用发布与分享时的同一套密钥扫描规则，以及密钥库里的明文值做脱敏，命中处替换成「〔已脱敏〕」。

## 了解每日整理与注入

每天整理一次主题：一个固定的「主人画像」，另有至多 12 个动态主题。助手启动时把这些主题（合计约 8,000 字）与最近 14 天的活动附在系统提示词末尾。注入内容按对话存快照，1 小时内重新拉起沿用快照。

## 了解助手怎样检索记忆

| 工具 | 作用 |
|---|---|
| `recall_memory` | 召回关于你的记忆，经判断模型重排，带出处与可信度分档 |
| `search_history` | 原文全文搜索 |
| `recall_engineering` | 只读的工程记忆 |
| `remember` | 记下你明确要求记住的内容：你的原话直接生效，否则进入待确认 |

`recall_memory` 先从 Hindsight 召回前 50 条，再交给判断模型逐条打 0–3 分：

| 得分 | 处理 |
|---|---|
| ≥ 2.0 | 正常给出 |
| 1.5–2.0 | 标注「部分相关」 |
| 低于 1.5 | 不给出 |

判断模型在「判断模型（召回重排）」卡里配置，默认用 Google Gemini Decisions API 的 `gemini-decision-1`，key 只写不读。没有配置、超时或返回 429 时，退回 Hindsight 的原始排序并标注「未经重排」，召回不会因此失败。

## 查看与纠正记忆

「助手记忆」页上可以：

- 打开「注入预览」，查看助手启动时附加的记忆段。
- 在「主题」里查看各主题的内容。
- 在「事实」里查看事实与出处，对错误的事实「设为失效」。
- 在「明确记忆」里审核待确认的条目：「批准」或「拒绝」。
- 在「助手记忆状态」卡查看 24 小时与 7 天的用量。

## 遗忘或排除来源

- **按来源遗忘**：在「来源」里对某个助手对话或工作线程点「按来源遗忘」，删除它写入的内容。
- **排除项目或对话**：在「排除项」里选择要排除的项目，或在单个助手对话页头的「对话操作」菜单里勾选「不进助手记忆」。被排除的对话或项目不再写入，已写入的随之遗忘。

## 限制

| 项 | 值 |
|---|---|
| 首次开启的回填范围 | 最近 30 天 |
| 写入扫描间隔 | 5 分钟 |
| 每回合写入的回复长度 | 600 字 |
| 动态主题 | 至多 12 个 |
| 注入的主题 | 合计约 8,000 字 |
| 注入的近期活动 | 最近 14 天 |
| 召回候选 | 前 50 条 |
