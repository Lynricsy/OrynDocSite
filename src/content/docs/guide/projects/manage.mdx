项目把一个代码库和它的线程、执行环境（orb）配置、定时任务与密钥放在一起。「项目」分区用来回答「这个代码库现在怎么样了」：侧栏首行是「总览」，其后每个未归档项目一行，显示名称和「N 个线程 · 多久前活跃」，按名称排序。

## 新建项目

在「总览」页点主按钮「新建项目」（或侧栏「总览」行尾的 `+`），进入 `/projects/new`。在「仓库」里三选一：

| 选项 | 含义 |
|---|---|
| 「已有仓库」 | 填外部 `https://` 仓库地址。控制面为它维护一份镜像，见[仓库浏览](/guide/projects/repo-browser/) |
| 「空白仓库（Oryn 托管）」 | 由 Oryn 保存正本，建好就带一个空树的初始提交 `Initial commit`，基线分支缺省 `main`，见[托管仓库](/guide/projects/hosted-repo/) |
| 「不带仓库」 | 项目没有仓库 |

托管与外部仓库不能互转：托管项目不能再填外部仓库地址，有外部仓库的项目也不能创建托管仓库。没有仓库的项目以后可以在设置「概览」的「托管仓库」卡里点「创建托管仓库」。

等价命令：

```bash
# 外部仓库
oryn project create <项目名> --repo <仓库地址> --branch <基线分支>
# Oryn 托管的空白仓库
oryn project create <项目名> --hosted
```

`oryn project create` 还可以用 `--setup` / `--resume` 给出环境脚本（内容，或 `@文件`）、用 `--provider` 与 `--type` 指定默认 Provider 与环境类型，全部参数见 [`oryn project`](/reference/cli/project/)。

## 查看项目总览

<Shot id="site/projects-overview" alt="项目总览列出三个项目，每行有图标、名称、描述与仓库地址、活动曲线、线程数和最后活跃时间" />

总览 `/projects` 一行一个项目，依次是徽标、名称、描述与仓库地址、近 14 天每天回合数的活动曲线、线程数和最后活跃时间，按最近活动排序。

- 线程数只算未归档、非协调对话的线程；最后活跃取其中最新一条的活动时间，没有线程时取项目创建时间。
- 用量被折叠进「其它」的项目不画曲线，全零时画一条平线。
- 页头 `⋯` 菜单里的「显示已归档项目」会在下面另起一张「已归档」卡。开关状态写进地址（`?archived=1`），刷新和切换分区后保持。

## 查看项目主页

<Shot id="site/project-home" alt="项目主页：仓库行与同步状态，状态条显示等你回复、工作中、打开的 PR 与近 7 天成本，下方是最近线程与基线分支的最近提交" />

项目主页 `/projects/<id>` 的页头是面包屑和几个按钮：复制项目链接、复制克隆命令、项目设置、新建线程。克隆命令对外部仓库是 `git clone <地址>`，对 Oryn 托管的仓库是 `oryn clone <项目名>`；没有仓库时没有这个按钮。已归档的项目没有「新建线程」按钮；点它会回到首屏，项目已选好。

正文自上而下：

| 区块 | 内容 |
|---|---|
| 描述与仓库行 | 一行描述（最多 200 字，在设置「概览」里填）；仓库地址前的图标区分 GitHub 与其它 Git，Oryn 托管的仓库显示「Oryn 托管」，后面是基线分支；没有仓库时显示「无仓库」 |
| 状态条 | 等你回复的线程数、工作中（含准备环境中）的线程数、打开的 PR 数（CI 失败的数量用红字追加在同一项里）、最近一次环境 setup 失败、近 7 天的成本与回合数。数值为 0 的项不显示，全部为 0 时整条不占位 |
| 最近线程 | 最近活动的 5 个线程（含已归档的），「查看全部」进线程子页 |
| 服务 | 本项目环境上的受管服务，失败和已停止的也列出；没有服务时不显示 |

状态条的前三项链到线程子页的「活跃」筛选；setup 失败一项链到出事的线程，没有线程时链到设置的「环境」分组；成本一项链到统计页（`/stats/usage?range=7d&project=<id>`）。

有仓库的项目在主页上还有提交、文件与 README 区块，见[仓库浏览](/guide/projects/repo-browser/)。

## 筛选项目的线程

线程子页 `/projects/<id>/threads` 用来找本项目的线程；线程分区侧栏没有项目过滤签。

- 搜索框匹配线程标题与标签，多个词都要命中。
- 状态分「全部 / 活跃 / 已归档 / 已交付」四档，各档可以重叠：已交付的线程同时算在「活跃」或「已归档」里。
- 搜索词与状态都写进地址（`?q=`、`?status=`），切走再回来筛选保持。
- 每行显示状态、PR 与 CI、交付与归档徽标、最后活动时间。

## 修改项目设置

设置在 `/projects/<id>/settings/<分组>`。宽屏左边是分组导航、右边是内容；窄屏先是一页分组列表，点进去看内容，面包屑里的「设置」返回列表。

| 分组 | 管什么 |
|---|---|
| 概览 | 名称、图标、描述、仓库地址与基线分支、git 作者；「仓库镜像」卡（外部仓库）或「托管仓库」卡（Oryn 托管或还没有仓库）；「危险操作」里的归档 / 取消归档与删除项目 |
| 环境 | 默认模型供应商、环境类型、浏览器 Profile、浅克隆、setup 与 resume 脚本；最近一次环境 setup 的结果；「快照与预热」（项目快照开关与预热环境数），见[环境配置](/guide/projects/environment/) |
| Agent | 项目级 Agent 配置与项目记忆开关，见[项目级 Agent 配置](/guide/agent/project-config/) |
| GitHub | 仓库绑定、事件回流、触发规则与推送门禁；仓库不在 GitHub 上时只给出改仓库地址的入口，见 [GitHub](/guide/automation/github/) |
| 定时任务 | 本项目的定时任务，见[定时任务](/guide/automation/schedules/) |
| SSH 主机 | 限定到本项目的 SSH 主机，见 [SSH 主机](/guide/automation/ssh-hosts/) |
| 密钥与环境变量 | 只注入本项目环境的环境变量与 Git 令牌，见[密钥与环境变量](/guide/projects/secrets/) |

设置项与分组的完整索引见[设置页索引](/reference/ui/settings/)。

## 归档项目

在设置「概览 → 危险操作」里归档，需要确认。归档后：

- 项目从侧栏收起。
- GitHub 仓库钩子被释放，预热环境清零，定时任务与触发规则停止运行。
- 线程都保留，仍可在总览的「已归档」区或直接打开项目地址查看，页面顶部有提示条和「取消归档」。
- Oryn 托管的仓库变成只读：能克隆，不能推送，也不能上传 LFS 对象。

取消归档不需要确认。项目回到侧栏，定时任务与触发规则重新生效。

## 删除项目

删除也在「概览 → 危险操作」里。删除项目时：

- 线程保留，但不再属于任何项目。
- 定时任务、Agent 配置、项目记忆与项目级密钥和环境变量一并删除。
- 外部仓库的镜像一起删除。

<Aside type="caution">
Oryn 托管的仓库随项目一起删除，包括全部分支、标签、提交与 LFS 对象，不可恢复。托管仓库没有别的副本，删除前确认已有备份，见[备份](/admin/operations/backup/)。
</Aside>
