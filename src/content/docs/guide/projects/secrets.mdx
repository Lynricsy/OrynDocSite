密钥与环境变量分全局与项目两层。全局的在「密钥」设置页管理；项目设置的「密钥与环境变量」分组存这个项目自己的环境变量与 Git 令牌，值只注入本项目的执行环境（orb）——setup 脚本、Agent、受管服务——别的项目看不到。设置项目条目不改变全局「密钥」设置页。

## 添加项目条目

在项目设置 →「密钥与环境变量」分组里添加。一张表里可以有两类条目：

| 类型 | 命名规则 | 注入方式 |
|---|---|---|
| 环境变量 | 大写字母、数字和 `_`，不能以数字开头 | 以环境变量下发给本项目的环境 |
| Git 令牌 | `git/<主机>/token`：在表单里选「Git 令牌」后填主机，主机名小写 | 不进环境，由出站代理在每次 git 请求时注入 |

模型供应商密钥（`omp/models/…`）只能在全局设置，见[模型与密钥](/guide/agent/models-and-keys/)。

等价命令（先 `oryn login`）：

```bash
# 不给值时从标准输入读取
oryn secrets set <名称> [值] --project <项目>
# 存为不保密的环境变量
oryn secrets set FOO bar --project myproj --plain
# 列出项目条目（保密的值显示 -）
oryn secrets ls --project <项目>
# 删除项目条目
oryn secrets rm <名称> --project <项目>
```

不给 `--mode` 时，`git/` 开头的名称按 Git 令牌、其余按环境变量。`--project` 只认未归档项目，已归档项目的条目在网页上改。

## 选择保密或不保密

环境变量可以勾「保密」，缺省勾选：

- **保密**：保存后值不能再查看，列表里只显示点，编辑时只能输入新值覆盖。把保密的条目改成不保密，也必须重新输入值。
- **不保密**：普通环境变量，值在列表里可见、可直接改。命令行用 `--plain`。

Git 令牌总是保密。

保密的值和全局密钥一样，参与分享前的密钥扫描与主人记忆脱敏，命中时显示为 `<项目名>:<变量名>`；不保密的值不参与。

## 从 .env 批量导入

在「批量添加」里粘贴 `.env` 内容，每行一个 `KEY=value`。支持：

- `#` 注释，包括值后面以「空白 + `#`」开头的行内注释；
- `export` 前缀；
- 单引号与双引号，双引号里认 `\n`、`\"`、`\\`。

不支持跨行的值。

预览逐项列出变量名与值，每项可单独勾「保密」（缺省勾选）；与现有条目同名的标出「覆盖现有」。缺 `=`、变量名不合规、值为空、引号没闭合、引号后有多余内容的行列在「以下行不会导入」里；重名的以后一行为准。导入逐项写入，失败的项留在对话框里并写明原因。

## 同名时用哪一个

环境变量同名时，后者覆盖前者：

1. 全局环境变量
2. 项目条目
3. 模型供应商密钥降级成的环境变量

Git 令牌按主机取：先项目、后全局。项目令牌读取出错时直接拒绝，不回落到全局令牌。github.com 例外：

- 环境归 GitHub 集成管时，一律用 OAuth 账号令牌；项目里设的 `git/github.com/token` 只在环境不归 GitHub 集成管时生效。
- 仓库镜像的拉取也不用项目里的 `git/github.com/token`，见[仓库浏览](/guide/projects/repo-browser/)。

## 何时生效

| 条目 | 生效时机 |
|---|---|
| 环境变量 | 环境下次启动时生效，正在运行的环境不变。改环境变量会使本项目的快照失效（新环境重新跑 setup），预热池随之按新配置对账 |
| Git 令牌 | 由出站代理在每次 git 请求时现取，改值立即生效，不影响快照。为一个新主机加令牌后，环境要下次启动才会把该主机的 git 请求交给出站代理 |

快照与预热池见[环境配置](/guide/projects/environment/)。

## 哪些地方拿不到项目条目

- Runner 线程（你自己的机器）与协调宿主不下发项目条目。
- 全局助手与 Space 协调者没有读写项目条目的工具。

项目条目会注入该项目的环境，包括由 GitHub 触发规则的「任何人」档或入站 Webhook 启动的全自动线程。对外开放的自动化入口放在不带敏感密钥的项目里，见[协调沙箱与不可信输入](/security/sandbox-untrusted/)。

## 凭据如何保护

全局密钥库里的 `git/*` 令牌存在控制面主密钥加密库里，下发到环境的配置只含 `oryn-ph-…` 占位符；请求经出站代理时，控制面按绑定的上游主机注入真实值，并把响应里回显的凭据脱敏回占位符。项目级的 Git 令牌同样只由出站代理注入、不进环境；项目级环境变量只以环境变量下发给本项目的环境。机制见[凭据隔离与出站代理](/security/credentials/)。

## 归档与删除

已归档的项目仍可在网页上查看与修改条目。删除项目时条目一并删除。
