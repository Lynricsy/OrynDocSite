技能、规则、命令和提示词决定 Agent 在每台执行环境（orb）里怎样工作。它们是全局 omp 配置里的文件，「设置 → 助手与 Agent → 技能与指令」把这些文件做成表单：每类一组，可以新建、编辑、删除和启停。这一页的改动下发到环境，不作用于全局助手。

只对某个项目生效的同类内容放在项目级配置里，见[项目级 Agent 配置](/guide/agent/project-config/)。

## 编辑技能

「技能」组的每个技能是 `skills/<名称>/SKILL.md`，Agent 按描述决定何时读取。

- 名称：小写字母、数字与连字符，以字母或数字开头，最长 64 个字符。
- 「描述」必填：写清楚什么时候用。没有描述的技能不会加载。

## 编辑提示词文件

「提示词文件」组是 omp 配置目录顶层的六个文件，未创建的可以直接创建：

| 文件 | 作用 |
|---|---|
| `AGENTS.md` | 全局上下文：每个会话都会读到的约定与偏好 |
| `RULES.md` | 常驻规则：全文随每次请求发送 |
| `APPEND_SYSTEM.md` | 追加到系统提示词末尾 |
| `PERSONALITY.md` | Agent 的语气与性格 |
| `TITLE_SYSTEM.md` | 生成会话标题时用的提示词 |
| `SYSTEM.md` | 替换整个内置系统提示词 |

`SYSTEM.md` 的内容会整段代替 omp 内置的系统提示词。只想追加内容时用 `APPEND_SYSTEM.md`。

## 编辑命令、规则、提示片段与指令文件

| 组 | 文件 | 说明 | 表单字段 |
|---|---|---|---|
| 「斜杠命令」 | `commands/<名称>.md` | 在输入框里用 `/<名称>` 调用，正文是展开后的提示词 | 「描述」「参数提示」 |
| 「规则」 | `rules/<名称>.md` 或 `.mdc` | 按描述与文件匹配按需加载，也可设为始终应用 | 「描述」「文件匹配」「始终应用」 |
| 「提示片段」 | `prompts/<名称>.md` | 可从 `/prompts` 菜单插入 | — |
| 「指令文件」 | `instructions/<名称>.md` | 处理与适用范围匹配的文件时附上 | 「适用范围」 |

- 「参数提示」是输入命令时跟在后面的灰字，例如 `<文件> [选项]`。
- 「文件匹配」是逗号分隔的 glob，例如 `src/**/*.ts`；「适用范围」是一个 glob，例如 `**/*.py`。
- 「始终应用」的规则每次请求都带上，不按需加载。
- 名称以字母或数字开头，可含字母、数字和 `.` `_` `-`，最长 64 个字符。

## 了解改动何时生效

保存后数秒内，改动下发到所有运行中的环境。

- 技能、命令、规则、上下文文件与 MCP：在会话空闲时热重载。正在跑回合的会话在回合结束后生效。
- `SYSTEM.md`、hook、扩展模块、自定义工具：要重启会话才生效。页面顶部列出受影响的会话，点「重启这些会话」安排重启：各会话空闲时才重启，正在跑的回合不受影响；下次发消息时带着原会话自动拉起。

某些环境没能下发时，页面顶部列出数量；这些环境会在下次启动或恢复时拿到最新配置，再保存一次也会重试。

编辑框打开后，如果文件在别处被改过，保存会提示冲突，你的改动保留；点「载入最新内容（放弃我的改动）」后再改。

## 用 /omfg 把纠错写成规则

Agent 做错时，在线程里执行 `/omfg` 吐槽它的错误做法，它会生成一条防止再犯的规则，并问「把这条规则保存到哪里？」：

- 「本项目（Oryn 项目配置）」：写进本项目的 Agent 配置。
- 「全局（Oryn 中央配置）」：写进全局 Agent 配置。

规则写回控制面后，当前线程立即生效，其它环境在新建或下次唤醒时拿到。

- 同一线程同时只能有一个 `/omfg`。
- 写回的规则必须与你确认时看到的预览一致，否则不写入，需要重新执行 `/omfg`。
- 控制面已有同名但内容不同的规则时不覆盖，需要到 Agent 配置里手工合并。

## 编辑原始文件

表单之外，「设置 → 助手与 Agent → 配置文件」是全局 omp 配置的文件浏览器，可以直接编辑任何文件。在本机维护配置目录时，用 `oryn config push` 整体上传，见[模型与密钥](/guide/agent/models-and-keys/)。

## 限制

- 技能、命令、规则、提示片段、指令文件的名称最长 64 个字符。
- 同一线程同时只能有一个 `/omfg`。
