角色（role）把一个名字映射到一个模型（可带思考档位后缀）；在线程里切换角色，就是切换到该角色的模型。角色写在全局 omp 配置的 `config.yml` 里，在「设置 → 助手与 Agent → 模型与角色」编辑；保存后下发到每台执行环境（orb），也下发给全局助手。

## 了解页面上的各个分组

| 分组 | 内容 |
|---|---|
| 「默认 Agent 身份」 | 普通对话回合头默认显示的名字与头像，见[头像与身份](/guide/agent/avatars/) |
| 「新会话」 | 「默认思考档位」 |
| 「轮换顺序」 | 参与切换的角色，按顺序排列 |
| 「其他角色」 | 不参与轮换的角色，仍可被 `@role` 引用或供内部功能使用 |
| 「遗留头像」 | 已不在 `config.yml` 里、只剩头像的角色，可以清除头像 |

页面列出的角色是三者的并集：`config.yml` 的 `cycleOrder`、`modelRoles` 的键，以及内置角色。

内置角色：

| 角色 ID | 界面名称 |
|---|---|
| `default` | 默认 |
| `smol` | 快速 |
| `slow` | 思考 |
| `vision` | 视觉 |
| `plan` | 架构 |
| `commit` | 提交 |
| `tiny` | 微型 |
| `memory` | 记忆 |
| `task` | 子任务 |
| `advisor` | 顾问 |
| `widget` | 任务小组件 |

## 给角色指定模型

在角色所在行点「设置」，对话框里有三项，改动即时保存：

- 「模型」：写入 `modelRoles`。可用 `provider/模型`、通配或 `:档位` 后缀，逗号分隔表示按顺序回退；也可以写 `@role` 引用另一个角色的模型。候选来自[模型目录](/guide/agent/models-and-keys/#刷新模型目录)。
- 「显示名」：写入 `modelTags.<role>.name`，留空用默认名称。
- 「头像」：见[头像与身份](/guide/agent/avatars/)。

没有配置模型的角色在行上显示「未配置模型」。

## 新建与删除自定义角色

点「轮换顺序」右上角的「新建角色」，填「角色 ID」和可选的「显示名」。角色 ID 以字母或数字开头，可含字母、数字和 `.` `_` `-`，最长 64 个字符，不能与已有角色重名。新角色加到轮换末尾，并直接打开它的设置对话框。

自定义角色的设置对话框里有「删除这个角色」：从 `config.yml` 移除它的轮换位置、模型与显示名；头像保留在「遗留头像」里，可另行清除。内置角色不能删除。

## 调整轮换顺序

`/model` 与输入框上的角色轨道按「轮换顺序」切换角色。

- 拖动行，或用行尾的上移、下移按钮调整顺序。
- 行尾的减号按钮把角色移出轮换，移到「其他角色」；轮换里至少保留一个角色。
- 「其他角色」行尾的加号按钮把角色加入轮换末尾。

`config.yml` 没有写 `cycleOrder` 时，轮换顺序是 `smol`、`default`、`slow`。

在线程页按快捷键沿轮换顺序切换：

| 操作 | 快捷键 |
|---|---|
| 下一个角色模型 | <kbd>Ctrl/⌘</kbd>+<kbd>P</kbd> |
| 上一个角色模型 | <kbd>Ctrl/⌘</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> |

全部快捷键见[键盘快捷键](/reference/ui/shortcuts/)。

## 设置默认思考档位

「新会话 → 默认思考档位」写入 `config.yml` 的 `defaultThinkingLevel`：新会话没有指定思考档位时从这里起步；模型自带默认档位时以模型为准。未设置时为「高」。

可选档位依次是「自动」「关闭」「最低」「低」「中」「高」「超高」「极限」。

## 了解一个回合实际用哪个思考档位

转录的回合头把模型放进胶囊，右下角用图标标出该回合的思考档位。首屏的角色弹层直接选中实际生效的档位，按以下顺序确定：

1. 显式指定的档位。
2. 模型自带的默认档位。
3. 会话起始档位：`default` 角色的显式档位，或 `config.yml` 的 `defaultThinkingLevel`。
4. 最后按模型能力收窄。

推不出实际值时，弹层只列可选档位、不选中任何一项。

## 限制

- 角色 ID 最长 64 个字符。
- 轮换顺序里至少保留一个角色。
