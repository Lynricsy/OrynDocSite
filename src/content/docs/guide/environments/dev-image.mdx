执行环境（orb）的开发镜像由 Oryn 仓库的 [`images/orb/`](https://github.com/Lynricsy/Oryn/blob/main/images/orb/) 构建。

## 基础系统

| 项 | 值 |
|---|---|
| 发行版 | 滚动更新的 Arch Linux |
| x64 基础镜像 | 官方 [`archlinux:latest`](https://hub.docker.com/_/archlinux) |
| ARM64 基础镜像 | 每日构建的 [`menci/archlinuxarm:latest`](https://github.com/Menci/docker-archlinuxarm) |
| 默认用户 | 非 root 用户 |
| 字符集 | UTF-8 |
| 时区 | `UTC` |
| 已在 `PATH` 里的目录 | `~/.local/bin`、`~/.cargo/bin`、`~/go/bin` 与 npm 全局目录 |

## 预装工具链

| 类别 | 预装工具链 |
|---|---|
| 语言与构建 | C/C++ (GCC/Clang)、Make、CMake、Ninja、Autotools、Go、Rust (`rustfmt`/`clippy`/`rust-src`)、Python (`pip`/`uv`/`pipx`/`ruff`)、Node.js (`npm`/`pnpm`/Bun)、Ruby/Bundler、PHP/Composer、Lua |
| 语言服务器 | 按 Oryn Core 内置 LSP 配置预装：`clangd`、`rust-analyzer`、`gopls`、`typescript-language-server`、`pyright`、`ruff`、`ruby-lsp`、`phpactor`、`lua-language-server`、`bash-language-server`、YAML / JSON / HTML / CSS / Dockerfile 语言服务器、`marksman` |
| 代码与协作 | Git、Git LFS、`gh`、OpenSSH、`rsync`、`ripgrep`、`fd`、`jq`、`yq` v4、`patch`/`diff`、ShellCheck、`shfmt`、常见归档解压工具（含 `unrar`/`cabextract`） |
| 排障与数据 | `ip`/`ss`/`dig`/`nc`/`socat`/`whois`/`nmap`/`iperf3`、`lsof`/`strace`/`ltrace`/`gdb`、`htop`/`ncdu`、SQLite / PostgreSQL / MariaDB / Valkey(Redis) 客户端、DuckDB、Miller、HTTPie、`aria2`、`yt-dlp` |
| 文档与媒体 | Pandoc、LibreOffice（`soffice --headless`）、Poppler/`qpdf`/Ghostscript/MuPDF/`img2pdf`、Tesseract OCR（英文、简繁中文）、ImageMagick、librsvg、WebP/AVIF/JPEG XL/HEIF 编解码、`optipng`/`pngquant`/`jpegoptim`/`gifsicle`、ExifTool、Graphviz、`qrencode`/`zbar`、FFmpeg、SoX、MediaInfo |
| Python 库 | 系统 Python 可直接 `import`：numpy、pandas、scipy、matplotlib、Pillow、requests、BeautifulSoup、lxml、PyYAML、openpyxl、XlsxWriter、python-docx、pypdf、ReportLab |
| 图形桌面 | TigerVNC (`Xvnc`)、Openbox、session D-Bus 与 AT-SPI 无障碍总线、受管策略加固的 Chromium、VS Code（微软官方版）、终端（`xfce4-terminal`）、文件管理器（`pcmanfm`）、文本编辑器（`mousepad`）、LibreOffice、中英文与彩色 Emoji 字体；等宽字体默认为 [JetBrains Maple Mono](https://github.com/SpaceTimee/Fusion-JetBrainsMapleMono)（中英文 2:1 对齐、带 Nerd Font 字形、无连字） |

ShellCheck、Pandoc、rust-analyzer、marksman、phpactor、JetBrains Maple Mono 从上游 GitHub 发行版安装（ARM 仓库缺包，双架构统一来源）。VS Code 按微软更新 API 的 `sha256` 校验安装官方 tarball。

## 清单文件

| 路径 | 内容 |
|---|---|
| `/usr/local/share/oryn/packages.txt` | 系统软件包 |
| `/usr/local/share/oryn/upstream-versions.txt` | 从上游发行版安装的工具与 VS Code 的版本 |
| `/usr/local/share/oryn/desktop-apps.json` | 桌面任务栏的应用清单 |
| `/usr/local/share/oryn/desktop-icons/` | 任务栏图标，取自镜像内各应用自带的文件 |

不含 `desktop-apps.json` 的自定义镜像，在任务栏里只有内置的 Chromium。

## 加装系统包

在项目的 `setup` 脚本里用：

```bash
sudo pacman -Syu --needed --noconfirm <包名>
```

setup 脚本的写法见[环境配置](/guide/projects/environment/)。

## BlackArch 源

镜像已启用 [BlackArch](https://blackarch.org/) 源（双架构）：

- 只导入经钉定签名主密钥校验的 keyring 与镜像列表，不预装安全工具。
- 该源排在官方源之后，同名包仍取官方版本。
- 其中的工具同样用上面的 `pacman` 命令安装。

## Shell 提示符

| 项 | 行为 |
|---|---|
| 交互 shell 提示符 | 只显示工作目录，如 `~/workspace $`；超过 3 级时前面折叠成 `~/.../a/b/c` |
| 上一条命令失败 | `$` 变红 |
| 窗口与终端标题 | 只显示工作目录，不带 `user@<orb ID>` |
| 字符 | 纯 ASCII，不用 Nerd 字形 |
| 非交互 shell | 不受影响 |
