*本页回答：Artifact 是什么、和视图有什么不同？*

Artifact 是 Agent 做出来、留在 Oryn 里的成品：一个页面、一张画布、一份文档、一套幻灯片，或者一个 Word / Excel / PowerPoint / PDF 文件。它有自己的地址、版本历史和评论，不随某条对话消失。执行环境（orb）里的线程、Runner 上的线程与全局助手的 Agent 都能创建和修改 artifact。

## 种类

| 种类 | 内容 |
|---|---|
| 页面 | 网页，可以带数据、读文件与提问等页面能力，见[发布 Artifact 与页面能力](/guide/artifacts/publishing/) |
| 画布 | 由画框组成的设计稿；在环境里的线程上可升级为多帧设计画布，见[设计画布与多版方案](/guide/artifacts/design-canvas/) |
| 文档 | Markdown 文档 |
| 幻灯片 | 按页组织的演示文稿 |
| Office 与 PDF 文件 | `docx docm xlsx xlsm pptx pptm pdf` 七种原生文件，以文件本身作为版本内容；表格文件归为「表格」类。见 [Word、Excel、PowerPoint 与 PDF](/guide/artifacts/office/) |

## 版本与「最近删除」

每次写入都生成一个新版本，冲突按文件粒度检查。你可以恢复旧版本。版本历史按 Agent 的回合折叠，每组以那一回合用户输入的首行作主标题，并带设计检查的徽标。

删除的 artifact 进入「最近删除」，保留 30 天后永久移除。在保留期内可以恢复。

## 隔离渲染

每个 artifact 都在一个不透明源的沙箱帧里显示，只能加载自身的文件与白名单 CDN 上的资源。管理员配置了 `portal_domain` 时，帧使用 `a-<令牌>` 形式的泛域名地址；没有配置时使用主域名下的 `/_af/` 路径。泛域名的配置见[启用 Portal 泛域名](/admin/install/portal/)。

缩略图、PNG、PDF 的渲染与设计检查，由控制面主机上一个带沙箱的 headless Chromium 完成。

## 入口

- 侧栏「更多」里的「Artifacts」总览页 `/artifacts`：大卡片预览、类型标签、搜索、筛选、「导入」与「最近删除」。
- 线程右面板的「Artifacts」页签。
- 转录里的 artifact 卡片。
- 命令面板（<kbd>Ctrl/⌘</kbd>+<kbd>K</kbd>），见[命令面板与全文搜索](/guide/threads/search/)。

## 查看器

每个 artifact 的查看器地址是 `/artifacts/<id>`，提供：

- 版本历史与恢复。
- 「评论」：评论可以发给线程处理。
- 元素直接编辑。
- 「演示」：页面与画布铺满窗口逐页演示；单个画框可「聚焦」全尺寸查看。手机上画布只读，演示时左右轻扫翻页。
- 在场：查看器与卡片上显示正在读、正在改这个 artifact 的线程头像；画布上显示 Agent 的指针，你可以跟随它的镜头。
- 导出与「分享」。分享即发布成链接，见[发布 Artifact 与页面能力](/guide/artifacts/publishing/)。

## 导出格式

| 对象 | 导出 |
|---|---|
| artifact | HTML / zip、Word、Markdown、PowerPoint、PDF |
| 设计画布（另外） | 样机 PNG / PDF、可运行的前端工程 zip |
| Office 与 PDF 文件 | 下载原件；Word / PowerPoint 另可打印成 PDF |

## 与视图的区别

视图是 Agent 在对话里直接给出的交互界面，例如一张表单或一块指标看板。两者的分工如下：

| | Artifact | 视图 |
|---|---|---|
| 存在于 | Artifacts 列表与查看器，有自己的地址 | 转录里，随对话走 |
| 版本 | 每次写入一个新版本 | 一次性回答，没有版本 |
| 用途 | 要留存、迭代或发布的成品 | 回合里要你看一眼或作答的内容 |
| 发布 | 可发布成私有、访问码或公开链接 | 只随线程的公开分享出现 |

详见[视图：对话里的交互界面](/guide/artifacts/views/)。

## 在环境里用命令行操作

环境里的 Agent 与你在终端里都可以用 `oryn artifact` 操作 artifact，例如修改 Office 文件前用 `oryn artifact pull` 把文件取回到环境里。这组命令只在执行环境内可用，参数见 [`oryn artifact`](/reference/cli/artifact/)。
