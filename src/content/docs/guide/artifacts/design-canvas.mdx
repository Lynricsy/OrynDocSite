画布是由画框组成的 artifact，用来做界面设计稿与原型。你要让 Agent 出一版界面、比较几种方向、再把选中的方案交付成可运行的前端时，用画布。

画布有两种形态：

- **HTML 画框画布**：每个画框是一段 HTML。全局助手与 Runner 上的线程做出的画布是这种。
- **设计画布**：执行环境（orb）里的线程可以把画布升级为 TSX + Tailwind v4 的多帧设计画布。`src/frames/_layout.tsx` 是各帧共享的外壳，`src/package.json` 声明额外依赖，帧之间用 `<Link to>` 跳转。

## 在画布编辑器里调整

画布的查看器带画布编辑器：工具条、图层面板与属性面板。

- 画框可以声明调节参数。在属性面板的「调节」页里改参数会即时预览，并写回画框。
- 选中画框或标注后用「交给 Agent」，选中的内容连同一张合成图一起发给 Agent。
- 在画布上加的评论与便签默认自动投递：30 秒去抖后，在创建这张画布的线程空闲时发过去，由 Agent 处理并回复。自动投递可以按 artifact 关闭。

设计画布里，源码生成的画框不能直接编辑。点选一个元素会按 `src/frames/<文件>:<行>` 定位到源码。

## 切换实时与静态预览

设计画布的查看器顶栏有「实时」/「静态」切换，出现的前提是：

- 画布所在的线程有一台活跃的环境；
- 管理员配置了 `portal_domain`，见[启用 Portal 泛域名](/admin/install/portal/)。

实时模式下，离视口最近的至多 6 帧直连环境里的 Vite 开发服务，源码改动热更新。WebKit 浏览器的跨站握手受限时，查看器回退到静态帧，并提示「在新窗口授权实时预览」。

每个回合结束时，设计画布自动构建，封存源码与静态产物。离线查看、发布与缩略图都用这份静态产物。

查看设计画布的旧版本时一律显示静态帧，顶部提示「正在查看旧版静态帧，实时预览已暂停」。恢复旧版本后，下一回合环境里的工作副本自动对账。

## 让 Agent 检查设计品质

Oryn 内置 14 条无头浏览器探针规则，Agent 改完画布后用它们自查。回合结束时仍有未通过或未检查的改动，Agent 自动再跑一轮。

| 类别 | 规则 | 何时生效 |
|---|---|---|
| 版面（6 条） | 文字截断、意外折行、图标缺失、边缘错位、未定义 token、对比度不足 | 一直生效 |
| 审美（8 条） | 点击目标过小、文案破折号、眉标过多、多强调色、单一圆角、大面积纯黑白、重复分栏、内联原始颜色 | 选定视觉方向后启用；`app` 面不检查眉标过多与重复分栏两条 |

Agent 还可以用方向牌选定视觉方向，并按选定的方向生成语义 token。

## 并排比较多版方案

同一屏的几种方案（不同方向、结构、文案或交互）做成一个「方案组」，并排放在画布上。每组 2–4 版，每版附一句话说明差别。Agent 在方向拿不准、需求含糊或有明显取舍时会主动出多版；也可以用三张方向牌各做一版，每版带自己的色板与字体。

<Shot id="site/artifact-variants" alt="画布上的一个方案组并排三版首屏方案：冷静克制、暖调杂志、高对比，每版右上角有「选定此方案」按钮，Agent 的指针正停在暖调杂志那一版上" />

点某一版上的「选定此方案」：

- 落选的画框自动移到备选方案页，不再参与品质检查，也不进样机、导出工程、部署与原型。想换一版时用「改选此方案」移回。
- 设计画布上的选定随便签自动通知 Agent，下一回合把选中方案的主题统一到画布上其余各帧。
- HTML 画框画布在选定后提示「让 Agent 统一到此方案」，点一下交给 Agent 统一。

## 预览原型与导出样机

画框可以套用 `none`、`phone`、`tablet`、`browser` 四种设备外壳。画布按 `<Link>` 只读绘制帧之间的连线。原型模式从起始帧开始单帧交互预览，点击链接时同步切换帧名、尺寸与外壳。

可以导出两种成品：

- 「导出样机…」：导出 PNG 或 PDF 样机，可以设置帧范围、缩放、圆角、边框、阴影、背景、设备外壳与长图。
- 「导出工程（.zip）」：导出可运行的前端工程，包含源码、锁文件与 `.oryn/box.yaml`。

## 部署到 box

设计画布可以直接上线成 box 上的一个应用，两种方式：

- 在 artifact 的菜单里选「部署到 box」：Oryn 给创建这张画布的线程发一条消息，由那里的 Agent 把画布导出到环境里的 `~/box-<artifact-id>` 目录、初始化提交并部署。
- 在环境里先导出成独立工程并提交，再部署：

  ```bash
  # 导出到一个空目录或尚不存在的目录
  oryn design eject <artifact-id> --to <目录>
  # 在导出的目录里初始化提交后部署
  oryn boxes deploy --on <box> --name <应用名>
  ```

`oryn design eject` 只在执行环境内可用，`--version` 导出指定版本，参数见 [`oryn design`](/reference/cli/design/)。部署的完整步骤见[部署第一个应用](/guide/boxes/deploy-app/)。

## 限制

| 项 | 上限 |
|---|---|
| 每个方案组的版数 | 2–4 |
| 实时预览同时直连的帧 | 6 |
| 长图样机的高度 | 8000 px |
| 品质规则 | 14 条（版面 6、审美 8） |
| 评论与便签自动投递的去抖 | 30 秒 |
