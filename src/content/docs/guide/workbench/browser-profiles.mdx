浏览器 Profile 是一份浏览器登录态，取自执行环境（orb）桌面上 Chromium 的 `Default` 配置目录，加密保存在控制面。你在一个线程的桌面里登录过网站，把登录态存进 Profile，之后的线程装载同一个 Profile 就不必重新登录。一个 Profile 可以在多个线程间复用，但同一时间只有一台环境能把改动写回。

远程桌面本身的用法见[远程桌面与人机接管](/guide/workbench/desktop/)。

## 创建与管理 Profile

在「设置」的「工作区」分组里打开「浏览器 Profile」：

- 「新建 Profile」：填名字（例如「工作账号」）。新建的 Profile 是空的，第一次在桌面里登录并保存后才有内容。
- 每个 Profile 显示保存时间与当前状态：「空闲」、「使用中」（及正在用它的线程）、只读副本的数量，或「上次保存失败」及原因。
- 「重命名」与删除：删除 Profile 会一并删除它保存的登录态，引用它的项目默认值也会被清除。正被某台环境独占使用的 Profile 不能删除，要先在那个线程的桌面面板里解除。

## 为项目设默认 Profile

在项目设置的「环境」分组里设置「默认浏览器 Profile」。这个项目的新线程默认装载它，新建线程时可以改。

## 新建线程时选择 Profile

在首屏新建线程时，可以选择本次装载的「浏览器 Profile」，或选「不用 Profile」。不选时使用项目默认值。

命令行上用 `oryn thread new` 的参数：

```bash
# 装载名为「工作账号」的 Profile（也可以写 id；写 none 表示不用）
oryn thread new "<任务描述>" --browser-profile 工作账号
```

Profile 只对新建的环境有效：`--browser-profile`、`--readonly`、`--takeover` 不能与 `--orb`、`--box` 或 `--runner` 同时使用；连同环境一起分叉出的新环境也不带 Profile。

## 在桌面面板里切换与保存

「桌面」页工具条左侧显示当前 Profile（「浏览器 Profile：」后接名字）。点开后可以：

- 切换到另一个 Profile，或选「不使用 Profile」。切换时当前浏览器会被关闭；独占使用的 Profile 会先保存。
- 「立即保存」：保存成功后提示当前是第几版。
- 「管理 Profile…」：打开设置里的 Profile 列表。

独占使用时，登录态在以下时机自动保存：环境冻结前、停机或删除前、切换 Profile 前。

环境冻结、停机、失败或删除时，它对 Profile 的占用随即释放；这台环境下次运行时自动取回，期间显示「已释放，下次运行时自动取回」。

## 处理占用冲突

同一个 Profile 被另一台运行中的环境独占使用时，新线程或切换操作会弹出「正在使用中」对话框，写明是哪个线程从何时开始在用。选一种方式继续：

| 选择 | 结果 |
|---|---|
| 「只读使用」 | 用最近一次保存的版本；这里的改动不会保存。不影响正在使用它的线程 |
| 「接管」 | 先保存对方的登录态再转到这里；对方转为只读 |

命令行上遇到占用会报错并提示这两个参数：

```bash
# 只读副本：不取得占用、不回写
oryn thread new "<任务描述>" --browser-profile 工作账号 --readonly

# 接管：对方降级为只读
oryn thread new "<任务描述>" --browser-profile 工作账号 --takeover
```

两个参数不能同时使用。

### 被接管的一方

被接管的线程里，浏览器照常运行、标签页不动，只是此后不再回写。桌面面板与线程信息显示「只读 Profile · 已被「线程名」接管」。要重新写回，只能反过来再接管一次，对方同样降为只读。

### 只读使用的一方

只读使用时，桌面上方提示「用的是最近一次保存的版本，这里的登录态改动不会保存。」。持有者之后保存的新版本不会推送过来。要改为独占使用，点「写回…」：这里的浏览器会被关闭，并装载这个 Profile 最新保存的版本；被别的线程占用时可以接管。

## 处理保存与装载失败

保存失败时，Profile 列表显示「上次保存失败」及原因：

| 原因 | 含义 |
|---|---|
| 「超过 256 MiB」 | 登录态打包后超过上限 |
| 「导出出错」 | 从环境导出登录态时出错 |
| 「接管前没能保存原线程的登录态」 | 接管时没能先保存对方的登录态 |

装载失败时，桌面面板显示「装载失败」及原因，例如归档已损坏（可以解除后重新登录，或换一个 Profile）、解包后超过 2 GiB 上限、环境磁盘空间不足。处理后点「重试」。

## 限制

- 最多 50 个 Profile。
- 名字 1–40 个字符，全局唯一。
- 登录态打包后不超过 256 MiB；解包后不超过 2 GiB、不超过 200000 个条目。
- 同一时间只有一台环境能独占使用（写回）一个 Profile；只读副本不限。
