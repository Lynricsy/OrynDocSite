每台执行环境（orb）带一块常驻的图形桌面。Agent 的 `browser` 工具操作桌面上的 Chromium，`computer` 工具作用于同一块屏幕。你在线程右侧的「桌面」页实时观看，遇到登录、验证码、二次验证这类只能由人完成的步骤时，由你接管操作，完成后交还。

## 看懂桌面的控制状态

桌面的控制状态由环境里的 `orbd` 统一维护，所有设备看到的一致。共四种，按优先级从高到低：

| 状态 | 何时出现 | 「桌面」页的样子 |
|---|---|---|
| 等你操作 | Agent 请你在桌面上完成某件事 | 放开输入；横幅显示事项与原因，带「完成」「跳过」 |
| 用户已接管 | 你点了「接管」 | 放开输入；横幅「你在操作桌面」，带「交还」 |
| Agent 操作中 | 这台环境上有线程处于回合中 | 只读观看；横幅「Agent 正在操作桌面」，带「接管」 |
| 空闲 | 其余情况 | 放开输入 |

在环境里运行 `oryn orb desktop status` 可以看到同一份状态（其中 `control <状态>` 一行）。

## 接管与交还

Agent 操作中时，点横幅上的「接管」。接管后：

- Agent 的浏览器操作暂停，直到你交还。暂停期间 Agent 发出的每条浏览器命令最多等待 45 秒，超时后命令返回错误，说明用户已接管桌面。
- Agent 会收到一条以 `[Oryn]` 开头的消息，告知你已接管；交还时同样会告知。
- 在画面上按 <kbd>Enter</kbd> 开始操作桌面；操作中单独按一下 <kbd>Ctrl</kbd>+<kbd>Alt</kbd> 把键盘交还给页面。

完成后点「交还」。你忘了交还时，以下任一情况会自动交还：10 分钟没有操作，或关闭桌面面板满 1 分钟。这 1 分钟用来容忍页面刷新、网络抖动和手机短暂切到后台。

<Aside type="caution">
接管只能暂停 Agent 的 `browser` 工具。`computer` 工具直接作用于屏幕，无法拦截；对它的约束只有接管时发给 Agent 的那条消息与系统提示词里的约定。
</Aside>

只想看、不想误触时，用桌面工具条上的「切换为仅观看（不发送键鼠）」。

## 回应 Agent 的操作请求

Agent 需要你登录、输入验证码或完成人工验证时，会停下来等你，线程进入等待输入状态。下面任一处都能作答：

- 「桌面」页横幅：标题是「需要你在桌面上」加事项（「登录」「输入验证码」「完成人工验证」或「操作」），带「完成」「跳过」。
- 线程卡片。
- 手机推送与 Telegram 通知，见[通知渠道](/guide/automation/notifications/)。

直接在桌面上输入，不要把密码或验证码发到聊天里。完成后点「完成」，Agent 会先确认结果再继续；点「跳过」，Agent 改用不需要你的做法。

## 使用任务栏里的应用

画面下方居中是网页绘制的任务栏（不占远端画面），依次为 Chromium、终端（`xfce4-terminal`）、VS Code、文件管理器（`pcmanfm`）、文本编辑器（`mousepad`）与 LibreOffice。运行中的应用下方有圆点。

- 点未运行的应用即启动它。
- 应用只有一个窗口时，点击在前台激活与最小化之间切换。
- 有多个窗口时，点击（或右键、长按、<kbd>Shift</kbd>+<kbd>F10</kbd>）弹出窗口列表，可以切换、关闭或「新建窗口」。
- 不属于这几个应用的窗口归入末尾的「其它窗口」。
- Agent 操作中点任务栏，会先询问「接管桌面后再打开？」，接管后再执行。

画面中央只有「启动浏览器」按钮、没有任务栏时，说明这台环境的 `orbd` 是旧版本。

Agent 可以直接读取这些应用的无障碍树，不只靠截图加坐标操作。

## 复制粘贴

剪贴板不会自动同步。焦点在桌面上时按 <kbd>Ctrl</kbd>/<kbd>⌘</kbd>+<kbd>V</kbd>，会把本机剪贴板粘贴进去；桌面里复制的文字，在桌面工具条的「剪贴板」里点「复制到本机」才会写入本机剪贴板。

## 观看 Agent 的录屏

Agent 可以用 `desktop_record` 把桌面操作录成视频：按 15 fps H.264 写入环境内的 `$HOME/recordings/*.mp4`。录制停止后，对话里出现可以直接播放的视频卡片；点击播放时才请求文件，打开对话不会唤醒冻结的环境。视频保存在线程的环境里，环境删除后随之删除。

为了不录进人工操作，你接管桌面、Agent 请你操作或回合结束时，录制先自动结束；在「用户已接管」与「等你操作」状态下，Agent 不能开始录制。

全局助手在它的电脑上用 `computer_record` 录制，停止后存入文件库，见[助手的电脑](/guide/assistant/computer/)。

## 让桌面自动恢复工作现场

在仓库里放一个可执行的 `.oryn/desktop/resume` 脚本，桌面每次启动后会执行它，用来打开常用的窗口。查找顺序、触发时机与日志位置见 [`.oryn/desktop/resume` 参考](/reference/project-files/desktop-resume/)。

## 限制

- 单次录制最长 10 分钟，环境里保留最近 20 个录像文件。
- 每台环境最多 8 个窗口同时打开桌面。
- 自动交还：10 分钟没有操作，或关闭桌面面板 1 分钟后。
- 多个线程或助手对话共用同一个桌面时没有租约，同时操作界面会互相干扰。
- 「助手的电脑」平时处于空闲状态；在空闲状态下开始的录制期间，如果你同时在桌面面板里操作，你的输入会被录进视频。
- 镜像早于桌面功能的环境没有桌面，新建线程即可使用。
