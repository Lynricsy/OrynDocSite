「信息」是线程右侧面板的第一个页签，集中显示这个线程的执行环境（orb）现在的状态：资源曲线、上下文构成、待办，以及服务、环境、浏览器 Profile、能力与 SSH 主机这些入口。排查「环境为什么没反应」「Agent 现在在干什么」时先看这里。

<Shot id="site/info-panel" alt="信息页自上而下是环境卡（状态、规格、运行时长）、CPU 与内存曲线、上下文占用条、待办清单，以及服务、环境、浏览器 Profile、能力等入口行" />

## 查看环境状态与资源

页面顶部是环境卡：徽记由 CPU 采样表圈和状态核心组成，环境故障时标红。徽记旁写着环境状态，例如「就绪」「已冻结」「已停机」「唤醒中」「失败」。卡片下方是 CPU 与内存的色块和曲线，以及「上下文」：当前会话占用的上下文与它的构成。

<Shot id="site/orb-card" alt="环境卡特写：状态为「就绪」，下方是 CPU 与内存曲线，以及按工具输出、工具定义、工具调用等分色的上下文占用条" />

界面上不显示环境编号。需要排查时，把鼠标悬停在信息面板上可以看到它。

线程没有环境时，这一页显示「线程没有 orb（只读）。」。

## 唤醒停机的环境

环境停机后，打开线程不会自动唤醒它，因为停机的环境要冷启动。在环境卡上点「唤醒」即可，发一条消息也会唤醒它。冻结、停机与唤醒的规则见[环境如何随线程生灭](/guide/environments/lifecycle/)。

## 展开入口行

服务、环境、浏览器 Profile、能力与 SSH 主机是一层入口行，点开就地展开明细，不离开这一页。

| 入口 | 展开后看到什么 |
|---|---|
| 服务 | 本环境的受管服务与状态；故障的服务可以就地重启（见下一节） |
| 环境 | `setup` 与 `resume` 的运行记录、耗时与日志；失败时给出原因与「新开线程修复」 |
| 浏览器 Profile | 当前装载的 Profile 与使用方式（如「独占使用」），见[浏览器 Profile](/guide/workbench/browser-profiles/) |
| 能力 | 当前会话加载的技能、MCP 服务器、子 Agent 定义、钩子与配置警告 |
| SSH 主机 | 这个线程能用的 SSH 主机，可以「测试」、复制 `ssh <名>` 命令；全自动线程没被放行的主机标为「全自动不可用」 |

环境脚本本身的写法见[环境配置](/guide/projects/environment/)，SSH 主机的登记见 [SSH 主机](/guide/automation/ssh-hosts/)。

## 重启故障的服务

服务故障时，「服务」行显示故障数。展开后对故障的服务点「重启」，行内依次显示「重启中…」，随后是「已恢复」或「仍然失败」。服务的声明方式与状态含义见[受管服务与 Portal 预览](/guide/workbench/portal-services/)。

## 管理待办

「待办」是可交互的清单，显示 Agent 当前的任务进度。你可以在清单末尾「添加待办…」。每项的状态是「待办」「进行中」「已完成」或「已放弃」。

## 查看子 Agent 派发树

Agent 派出子 Agent 后，信息页列出派发树，标题旁显示运行中与总数。子 Agent 的配置见[子 Agent](/guide/agent/subagents/)。

## 查看与停止后台任务

转入后台的命令、代码与子 Agent 任务都列在「后台任务」里：运行中的排在前面，带走动的时长与最近一行输出。点开一项是任务详情：

- 「输入」：这次调用的命令或代码。
- 「输出」：运行中实时刷新，结束后显示最终结果。
- 「事件」：开始、输出匹配、完成、失败等时间线。
- 「详细信息」：任务 ID、所属 Agent、工作目录、超时、开始与结束时间。

任务运行中时可以在详情里就地确认后停止它，停止后状态为「已停止」。转录里后台任务的标记与事件行见[读懂转录与工具卡](/guide/threads/transcript/)。

## 查看与销毁沙箱

信息页的「沙箱」区块列出该线程的 Agent 沙箱：后端（Docker 或 KVM）、网络（「联网」或「断网」）、状态、剩余空闲时间与到期时刻。在用的沙箱可以点「销毁」，确认框写明：沙箱里正在跑的命令会被中止，里面的文件一并删除，不能恢复。已结束的沙箱显示结束原因，例如「空闲回收」「TTL 到期」「线程已归档」。

沙箱的用途、上限与命令行操作见 [Agent 沙箱](/guide/environments/sandboxes/)。
