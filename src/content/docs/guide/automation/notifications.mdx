你没在看的线程完成、等你作答或出错时，Oryn 生成一条通知；预算越线时也会发一条。通知列在侧栏的「通知」铃铛里，另外可以投递到浏览器的系统通知、手机推送，以及你添加的 Telegram、Webhook、ntfy、Bark 渠道。这些都在「设置 → 通知与预算」里配置。

## 了解何时会通知

| 事件 | 界面名称 | 何时触发 |
|---|---|---|
| `done` | 「完成」 | 线程从工作中或等待输入转为空闲 |
| `input` | 「需要输入」 | 线程出现新的待答请求，包括计划审批 |
| `error` | 「出错」 | 线程转入出错状态 |
| `budget` | 「预算告警」 | 用量越过预算的预警线或上限，见[成本统计与预算](/guide/automation/stats/) |

- 有设备正在看该线程时不通知。
- `done` 与 `error` 去抖 3 秒，`input` 去抖 2 秒。去抖期间线程回到工作中、被你查看或操作、请求被作答，通知都会取消。
- 预算告警与不属于任何线程的出错通知立即生成，不去抖。
- 自动化回合里 Agent 以 `[SILENT]` 结束时不发完成通知，见[定时任务](/guide/automation/schedules/)。

通知保留 30 天。

## 在浏览器里接收系统通知

在「设置 → 通知与预算」的「此设备」一节：

1. 「系统通知」显示「未设置」时，点「允许系统通知」并在浏览器里允许。
2. 打开「后台推送」。通知经浏览器的推送服务（Web Push）送达。

「其它已订阅的浏览器与设备」列出别处的订阅，可以「移除订阅」。

## 添加渠道

在「设置 → 通知与预算」的「渠道」一节点「添加渠道」，选 Telegram、Webhook、ntfy 或 Bark。每个渠道都有：

| 字段 | 说明 |
|---|---|
| 「名称」 | 渠道名称 |
| 「发送哪些事件」 | 勾选「完成」「需要输入」「出错」「预算告警」中的若干项 |
| 「消息语言」 | 渠道里固定文案的语言：「简体中文」或「English」 |
| 「连接配置」 | 因渠道而异，见下文 |

连接配置里的机密字段只写不读：保存后不回显，填写任一项即整组替换原配置。渠道行上的「测试」发送一条测试消息。

### Telegram

| 字段 | 说明 |
|---|---|
| 「Bot token」 | 向 @BotFather 创建机器人得到 |
| 「Bot API 地址」 | 可选，留空用官方地址 |

Telegram 渠道至多一个。创建后按提示绑定私聊：在 Telegram 里打开你的机器人，发送界面上给出的 `/start <码>`。绑定码 8 位，10 分钟内有效。渠道只接受绑定的那一个私聊。Oryn 用长轮询收消息，不需要公网入站。更换 Bot token 会清掉绑定。

### Webhook

| 字段 | 说明 |
|---|---|
| 「URL」 | 接收通知的地址 |
| 「签名密钥」 | 可选 |
| 「自定义请求头」 | 可选，每行一个 `Name: value`，至多 16 个 |

Oryn 以 `POST <url>` 投递，请求头包括 `Content-Type: application/json`、`User-Agent: Oryn/<版本>`、`X-Oryn-Event: <事件>` 与你配置的自定义头。设了签名密钥时另带：

```text
X-Oryn-Signature: sha256=<hex(HMAC-SHA256(密钥, 请求体))>
```

`X-Oryn-Event` 的取值：`thread.<kind>`（`kind` 为 `done`、`input`、`error`）、`budget.alert`（预算告警）或 `test`（测试）。

请求体的键：

| 键 | 说明 |
|---|---|
| `event` `id` `ts` | 事件、通知 id、时间 |
| `thread` | 有线程时出现：`id`、`title`、`state`、`url` |
| `url` | 没有线程时出现，绝对地址；这时不出现 `thread` 键 |
| `title` `body` | 通知的标题与正文 |

接收方应忽略不认识的 `event`。

### ntfy

| 字段 | 说明 |
|---|---|
| 「服务器」 | 可选 |
| 「Topic」 | 必填 |
| 「访问令牌」 | 可选；填了以 `Authorization: Bearer` 发送 |

`input` 通知的优先级为 4，其余为 3。

### Bark

| 字段 | 说明 |
|---|---|
| 「服务器」 | 可选 |
| 「Device key」 | 必填 |

Bark 返回 HTTP 200 且 `code == 200` 才算投递成功。

## 在手机上接收

手机 App 的推送经官方推送网关或 UnifiedPush 送达，端到端加密。配置见[手机推送](/guide/clients/push/)。服务器只在没有任何设备正在看该线程时生成通知；App 在前台时只显示应用内提示，不弹系统通知。

## 在通知上直接作答

Agent 的提问只需点一个选项时，通知下方直接带按钮，正文是完整的问题。带按钮的条件：

- 待答请求是单选、是 / 否确认或工具审批这类单选题，不含文字输入、密钥、多选、多题、表单与计划审批。
- 选项 2–3 个，每个是不超过 24 字符的单行文字。
- 完整问题（工具审批含 `Allow tool: …` 与要执行的命令）不超过 300 字符。

问题会被截断时不带按钮，只发普通通知，点按打开线程作答。

各处的作答方式：

| 位置 | 作答方式 |
|---|---|
| 浏览器系统通知 | 点按钮；通知被替换为作答结果，不打开窗口。按钮数超过浏览器支持的上限时一个都不显示 |
| Android App | 点按钮，不打开 App；锁屏上必须先解锁。细节见[手机推送](/guide/clients/push/) |
| Telegram | 点通知上的按钮，或回复这条通知。回复其它通知则把内容发给该线程：线程工作中时作为引导，否则开启新回合 |
| 收件箱 | 「等你处理」的行内显示问题原文与选项按钮 |

请求在别处作答或被取消后，Oryn 撤回仍带按钮的推送，或把它换成「已在别处作答」。

## 查看投递状态

每个投递目标各有一条投递记录。网络错误、408、429 与 5xx 会重试，间隔 10 秒、60 秒、5 分钟，共 4 次尝试；其余 4xx 不重试。创建超过 1 小时仍未送达的投递记为失败（`expired`）。

## 限制

| 项 | 值 |
|---|---|
| 通知保留 | 30 天 |
| 去抖 | `done` / `error` 3 秒，`input` 2 秒 |
| 单次投递 HTTP 超时 | 15 秒 |
| 重试 | 10 秒、60 秒、5 分钟，共 4 次尝试；超过 1 小时未送达即失败 |
| Telegram 渠道 | 至多 1 个；绑定码 8 位、10 分钟有效 |
| Telegram 按钮 | 至多 8 个，每个至多 40 字符；正文至多 3500 字符 |
| Webhook 自定义请求头 | 至多 16 个 |
| Web Push 载荷 | JSON 至多 3000 字节，正文截到 300 字符 |
| 一触作答 | 选项 2–3 个，每个至多 24 字符；完整问题至多 300 字符 |
