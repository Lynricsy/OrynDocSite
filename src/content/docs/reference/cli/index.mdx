`oryn` 是 Oryn 的命令行客户端。每个命令的完整参数见各命令页，页面内容原样收录 `oryn <命令> --help` 的输出。控制面、环境守护进程与推送网关的命令行见 [orynd](/reference/cli/orynd/)、[orbd](/reference/cli/orbd/)、[oryn-push-gateway](/reference/cli/oryn-push-gateway/)。

## 运行位置

| 位置 | 判定 | 与控制面的连接 |
|---|---|---|
| 你的电脑 | 不满足下面两行的条件 | 读取登录凭据（见下一节），调用控制面 REST API |
| 执行环境（orb）内 | 环境变量 `ORYN_ORB` 为 `1`，且 `ORYN_API_TOKEN` 为空 | 经环境内 orbd 的本地控制口 `~/.oryn/orbd.sock`；调用方线程取自环境变量 `ORYN_THREAD_ID` |
| Provider 主机 | 只用于 `oryn provider run` 与 `oryn provider preflight` | 读取 Provider 配置文件（缺省 `/etc/oryn/provider.yaml`），不使用登录凭据；`run` 还读取 `token_file` 指向的 Provider 令牌 |

- 「你的电脑」指任何持有登录凭据的位置。在环境内同时设置了 `ORYN_API_URL` 与 `ORYN_API_TOKEN` 时，`oryn` 也按这一行处理，改走控制面 REST API。
- `oryn orb setup`、`oryn orb service`、`oryn orb desktop` 只检查 `ORYN_ORB` 是否为 `1`，不看 `ORYN_API_TOKEN`。
- Runner 上的线程设置 `ORYN_RUNNER=1`，不设置 `ORYN_ORB`，因此只能在环境内使用的命令在 Runner 上不可用。
- 在环境内调用只能在环境外使用的命令时，报调用错误，退出码 2：

```text
oryn: `oryn thread list` 在 orb 内不可用
```

## 凭据

`oryn` 按以下顺序取得控制面地址与令牌：

1. `ORYN_API_URL` 与 `ORYN_API_TOKEN` 都不为空时，直接使用这两个值。只设其中一个不生效。
2. `ORYN_CREDENTIALS` 指向的凭据文件。
3. 用户配置目录下的 `oryn/credentials.json`。Go 的 `os.UserConfigDir()` 决定该目录：Linux 上为 `$XDG_CONFIG_HOME`，未设置时为 `~/.config`；macOS 上为 `~/Library/Application Support`。

凭据文件不存在时，命令报错并以 1 退出：

```text
oryn: 尚未登录：先运行 `oryn login --url <服务器地址>`
```

凭据文件由 [`oryn login`](/reference/cli/login/) 写入，是一个 JSON 对象：

| 字段 | 内容 |
|---|---|
| `url` | 控制面地址 |
| `token` | 设备令牌（`odt_` 开头） |
| `deviceId` | 设备 id，可省略 |

文件总以 0600 权限写入：先写同目录的临时文件，再改名替换，已有文件的宽松权限不会沿用。使用缺省位置时，`oryn` 还把 `oryn` 目录的权限收紧为 0700；`ORYN_CREDENTIALS` 指向别处时，不改动其父目录的权限。

请求以 `Authorization: Bearer <令牌>` 发出。

## 退出码

出错时，`oryn` 在 stderr 打印 `oryn: <错误>`。

| 退出码 | 含义 |
|---|---|
| 0 | 成功 |
| 1 | 错误：未登录、控制面返回错误、参数解析失败，以及未归入下面各行的其它错误 |
| 2 | 调用错误：命令在当前位置不可用、参数组合不被接受、环境内的 orbd 控制口出错。少数参数校验失败返回 1 |

以下命令另有约定：

| 命令 | 退出码 |
|---|---|
| [`oryn thread wait`](/reference/cli/thread/) | 0 线程静止；2 调用错误；3 线程在等你回答；4 线程出错；124 等待超时 |
| [`oryn thread attach --exit-on-idle`](/reference/cli/thread/) | 见到一个回合结束后：idle 为 0，awaiting_input 为 3，error 为 4 |
| [`oryn sync`](/reference/cli/sync/) | 0 成功；1 运行或接口错误；2 前置条件不满足；3 本地改动或被忽略文件冲突 |
| [`oryn orb setup run`](/reference/cli/orb/) | 0 成功；1 失败；2 调用错误 |
| [`oryn orb service start`、`restart`](/reference/cli/orb/) | 0 全部服务 running；1 有服务不是 running；2 调用错误 |
| [`oryn orb desktop …`](/reference/cli/orb/) | 0 成功；1 未就绪、桌面未启用或启动失败；2 调用错误 |
| [`oryn boxes exec`](/reference/cli/boxes/) | 透传 box 上命令的退出码 |
| [`oryn sandbox exec`](/reference/cli/sandbox/) | 透传沙箱内命令的退出码 |
| [`oryn clone`](/reference/cli/clone/) | `git clone` 失败时透传其退出码 |
| [`oryn ssh test`](/reference/cli/ssh/) | 测试未通过时为 1 |
