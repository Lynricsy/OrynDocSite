参考页只列值：命令、键、字段、默认值与上限。要完成某件事，从[使用](/start/what-is-oryn/)或[部署与运维](/admin/overview/)的指南开始。

## 命令行

| 页面 | 内容 |
|---|---|
| [命令行总览](/reference/cli/) | `oryn` 的运行位置、凭据、退出码约定与全部命令的索引 |
| 各命令页，如 [`oryn thread`](/reference/cli/thread/) | 每个顶层命令一页，原样收录各级子命令的 `--help` 输出 |
| [orynd](/reference/cli/orynd/) | 控制面 `orynd` 的启动参数与管理子命令 |
| [orbd](/reference/cli/orbd/) | 执行环境（orb）里的守护进程 `orbd` 的参数，含在自己机器上接入 Runner 的 `--runner` 形态 |
| [oryn-push-gateway](/reference/cli/oryn-push-gateway/) | 自建推送网关的启动参数 |
